Workspace

WontNote · Your personal note space

WontNote is a clean desktop notepad designed to keep daily thoughts, study notes, project ideas, and work notes all in one place.

Create notes quickly, search by title or content, organize into folders, and pin your favorites. Accidentally deleted notes can be recovered from the trash.

How to use

  1. Press Ctrl+N to create a new note; type the title then move to the body.
  2. Use the note toolbar to pick font, size, and formatting.
  3. Assign a folder from the dropdown above; pin important notes.
  4. Search with Ctrl+F. Lock the vault with Ctrl+L when done.

Data & Security

Notes are encrypted with AES-256-GCM in a local vault on this device. Argon2id is used for key derivation. The app requires no internet connection and does not sync to the cloud.

The recovery key can also unlock the vault — keep it as secret as your password. If both are lost, notes cannot be recovered. Reset deletes all notes.

Anyone with access to this computer while the session is open can see your notes. Encryption does not fully protect against malware, screenshots, or OS administrators. Use a strong, unique password.
